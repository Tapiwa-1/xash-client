# API Client Command Line Tool

This is a command-line tool for interacting with the API to manage business-related tasks, including registering a user, setting a password, logging in, creating a business profile, and fetching business categories.

## Features

- **User Registration** - Register a new user.
- **Set Password** - Set or update the password for a user.
- **Login** - Login to the system and view the profile.
- **Create Business** - Create a new business profile.
- **Get Business Categories** - Fetch available business categories.

## Prerequisites

- Node.js v16.x or higher
- API endpoint URL and authentication key (provided by the API server)
- Basic knowledge of how to use the command line.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Tapiwa-1/xash-client.git
cd xash-client
```

### 2. Installation 

```bash
npm install
```

### 2. Execution

```bash
node index.js
```
